Clipper is a personal, single-operator automation project. It is not a commercial service, and these terms describe how the operator uses it — there is no public signup and no third party is granted access to the tool itself.

What the tool does

Clipper fetches clips that streamers have already made public on Twitch, generates short AI narration/commentary over them, renders a short-form video, and — after the operator manually reviews and approves each one — publishes it to the operator's own YouTube and TikTok accounts via those platforms' official APIs.

Platform compliance

All publishing is done through TikTok's Content Posting API and YouTube's Data API under the operator's own authenticated account, subject to each platform's own terms of service, community guidelines, and API usage policies. Nothing in this project is intended to circumvent platform rate limits, content policies, or review requirements (including TikTok's unaudited-app restrictions, which this project respects by defaulting new posts to private/self-only visibility until an app review clears).

No warranty

This is a personal hobby project provided as-is, with no uptime or accuracy guarantees. The operator is solely responsible for the content it publishes.
