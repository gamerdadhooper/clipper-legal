Privacy Policy

Last updated: 2026-10-20

Clipper is a personal, single-operator automation project. It does not collect data from, or act on behalf of, any user other than its operator — there is no public signup, account system, or multi-tenant usage.

What data is stored

  • OAuth credentials — API tokens issued by TikTok and YouTube to the operator's own accounts, stored locally in an environment file on the operator's machine. These are never transmitted anywhere except directly to TikTok's and YouTube's own APIs, and are never logged or committed to source control.
  • Clip metadata — publicly available Twitch clip information (titles, broadcaster names, view counts, clip URLs) used to generate commentary and attribution, stored in a local database on the operator's machine.
  • Generated content — rendered video files and AI-written commentary scripts, stored locally pending the operator's manual review before publishing.

What is not collected

No personal data is collected from viewers of the published videos, from TikTok or YouTube users, or from any third party. This tool has no analytics, no tracking pixels, and no user-facing signup of any kind.

Third-party services

This tool calls the Twitch Helix API, TikTok Content Posting API, YouTube Data API, and an AI text/speech provider (Anthropic and/or OpenAI/ElevenLabs) solely to generate and publish the operator's own content. Each of those services' own privacy policies govern their handling of data sent to them.

Data retention / deletion

All data is stored locally by the operator and can be deleted at any time by removing the local database and rendered files. Revoking API access via TikTok's or YouTube's account settings immediately invalidates the corresponding stored tokens.
